# flows/ — The three core user flows

Assembled in Phase 3, one per person. Each flow wires `ui/` to `data/` — it does
not reimplement trust, decay or claim IDs.

| Flow | Owner | Required reviewer |
|---|---|---|
| `rescue/` | assign in Phase 3 (whoever came out of Phase 2 deepest in trust-tier logic) | the other Phase-2 pairer |
| `report/` | assign in Phase 3 | the other Phase-2 pairer |
| `contribute/` | C | A or B |
